== Getting Started

This template provides sample pages demonstrating every major AsciiDoc feature.
Use it as a reference or starting point for your own documentation.

== Features Overview

[cols="1,2"]
|===
| Feature | Description

| xref:typography.adoc[Typography]
| Headings, paragraphs, inline formatting, and links

| xref:code-blocks.adoc[Code Blocks]
| Syntax-highlighted source code examples

| xref:admonitions.adoc[Admonitions]
| Note, tip, warning, caution, and important blocks

| xref:tables.adoc[Tables]
| Various table layouts and styles

| xref:blocks.adoc[Blocks & Quotes]
| Sidebars, examples, quotes, and literal blocks

| xref:lists.adoc[Lists]
| Ordered, unordered, and description lists

| xref:images.adoc[Images & Media]
| Image blocks and figure captions
|===

== Installation

Clone this repository and build with Antora:

[source,bash]
----
git clone https://github.com/the-dev-center/antora-demo-template.git
cd antora-demo-template
pnpm install
pnpm build
----

Then configure your `antora-playbook.yml`:

[source,yaml]
----
site:
  title: My Documentation
  start_page: component::index.adoc

content:
  sources:
    - url: .
      branches: HEAD
      start_path: docs

ui:
  bundle:
    url: https://gitlab.com/antora/antora-ui-default/-/jobs/artifacts/HEAD/raw/build/ui-bundle.zip?job=bundle-stable
    snapshot: true
----
